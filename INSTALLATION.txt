========================================
    MANGA READER - GUIDE D'INSTALLATION
========================================

📦 MÉTHODE 1 : INSTALLATION PROPRE (Recommandée)
================================================

1. Double-cliquez sur : clean-install.bat
   → Cela nettoie et réinstalle toutes les dépendances

2. Lancez l'application avec : start.bat


🖥️ MÉTHODE 2 : CRÉER UN .EXE AVEC ICÔNE (Application Windows complète)
========================================================================

1. Double-cliquez sur : build-app.bat
   → Cela va créer un vrai fichier .exe Windows

2. Attendez la fin de la construction (peut prendre 5-10 minutes)

3. Allez dans le dossier "dist"

4. Double-cliquez sur "Manga Reader Setup.exe"

5. Suivez l'assistant d'installation
   → Un raccourci sera créé automatiquement sur votre bureau
   → Une icône avec le logo Manga Reader sera affichée


📌 MÉTHODE 3 : RACCOURCI SIMPLE (Si vous ne voulez pas créer le .exe)
=====================================================================

1. Double-cliquez sur : create-shortcut.bat
   → Un raccourci "Manga Reader" apparaît sur votre bureau

2. Lancez l'application via le raccourci


⚙️ RÉSOLUTION DES PROBLÈMES
============================

Si l'application ne démarre pas :
1. Assurez-vous que Node.js est installé
   → Téléchargez sur : https://nodejs.org/

2. Réinstallez proprement avec clean-install.bat

Si les images ne s'affichent pas correctement :
1. Vérifiez que vos dossiers de manga sont bien structurés
2. Relancez l'application


📖 UTILISATION
==============

1. Lancez l'application (via .exe ou start.bat)

2. Cliquez sur le bouton "+" pour importer votre manga

3. Sélectionnez le dossier contenant vos chapitres/tomes

4. Profitez de la lecture !

Raccourcis clavier :
- Ctrl + : Zoom avant
- Ctrl - : Zoom arrière  
- F11 : Mode plein écran
- Échap : Quitter le plein écran
